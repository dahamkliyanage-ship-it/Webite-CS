Searching & Sorting

Searching for data and sorting data is at the absolute core of solving massive problems. Every algorithm requires a basic comparison function (like >, <, or ==), but they all possess vastly different performance characteristics in speed and memory usage.

THE SEARCH

A search algorithm simply provides a Boolean answer to whether a specific data item is present in a collection. If it is an ordered collection, it can also return its exact location.

THE SORT

A sort reorganizes a collection of items into a specific order based on their intrinsic values (like numerical order or alphabetical order).

THE SWAP

Sorting algorithms rely entirely on two things: comparing items to determine relative order, and rearranging those items to change their appearance in the collection using a swap() operation.

02. Search Algorithms

There are two primary ways to hunt down data, and the choice depends entirely on whether your list is currently sorted or totally chaotic.

1# Simple, but highly inefficient for massive lists.
2def sequential_search(a_list, item):
3 pos = 0
4 while pos < len(a_list):
5 if a_list[pos] == item:
6 return pos
7 pos += 1
8 return -1

1. Sequential Search

This algorithm simply iterates through an unordered list item by item. It is easy to implement, but in the worst-case scenario, it requires n comparisons (checking every single item).

2. Binary Search

Highly efficient, but it requires an ordered collection. It works by applying a "divide and conquer" strategy: comparing the middle item and deciding to search only the left or right half.

03. Basic Sorting Algorithms

These algorithms are relatively simple to write but suffer in performance when dealing with massive collections.

Bubble Sort

Makes multiple passes through a list, comparing adjacent items and swapping them if they are out of order. It places the largest item at its correct position on every pass.

Selection Sort

An improvement over Bubble Sort. It keeps track of the highest value during a pass, but only performs exactly one swap at the very end of that pass.

Insertion Sort

Maintains a sorted sublist at the bottom of the list. It takes each new item and performs faster "shift" operations (rather than full swaps) to insert it into the correct spot.

Shell Sort

Improves Insertion Sort by breaking the main list into smaller sublists separated by a "gap" increment, sorting those, and finishing with a final standard insertion sort.
