1. The Big Three Theorems on Closed Intervals

Definitions & Theorem Machinery[cite: 23, 24]

  • The Boundedness Theorem: Let $f:[a,b]\rightarrow\mathbb{R}$ be continuous. Then $f$ is bounded on $[a,b]$, meaning $\exists M\in\mathbb{R}, \forall x\in[a,b] (|f(x)|\le M)$[cite: 23].
    Proof Sketch: Assume $f$ is unbounded. Then a bounded sequence $x_n \in [a,b]$ exists where $|f(x_n)| > n$. By Bolzano-Weierstrass, a subsequence converges to $c \in [a,b]$. By continuity, $f(x_{m_n}) \rightarrow f(c)$ (a finite number). But $|f(x_{m_n})| > m_n \rightarrow \infty$, creating a contradiction[cite: 23].
  • The Extreme Value Theorem (EVT): Let $f:[a,b]\rightarrow\mathbb{R}$ be continuous. Then $f$ attains an absolute maximum and minimum on $[a,b]$[cite: 23].
    Proof Sketch: The image set is bounded (Boundedness Thm), so a supremum $s$ exists (Completeness Axiom)[cite: 23, 24]. A sequence of points $f(x_n) \rightarrow s$[cite: 24]. A subsequence $x_{m_n}$ converges to $c$, and by continuity, $f(c) = s$, proving the supremum is attained within the interval[cite: 24].
  • The Intermediate Value Theorem (IVT): Suppose $f$ is continuous on $[a,b]$ with $f(a)\ne f(b)$. If $u$ is any value strictly between $f(a)$ and $f(b)$, then there exists at least one $c\in(a,b)$ such that $f(c)=u$[cite: 24].

Exercise 1.2: One-Sided Continuity Stitching[cite: 25]
Let $f(x)=x+2$ for $x<1$ and $f(x)=x^{2}+1$ for $x>1$[cite: 25].
Left limit: $\lim_{x\rightarrow1^{-}}f(x)=3$. To make $f$ left-continuous, set $f(1)=3$[cite: 25].
Right limit: $\lim_{x\rightarrow1^{+}}f(x)=2$. To make $f$ right-continuous, set $f(1)=2$[cite: 25].
Can $f$ be continuous at 1? No. Because $3 \ne 2$, the two-sided limit does not exist, so no single value for $f(1)$ can make $f$ continuous[cite: 25].

Exercise 1.6: Closed Intervals[cite: 26]
If $f$ is continuous on $[a, b]$, then $f([a,b])$ is a closed interval[cite: 26]. By EVT, $f$ attains minimum $m$ and maximum $M$, so $f([a,b])\subseteq[m,M]$[cite: 26]. By IVT, every value between $m$ and $M$ is hit, so $[m,M]\subseteq f([a,b])$[cite: 26]. Therefore, the range is exactly $[m,M]$[cite: 26].

2. Uniform & Lipschitz Continuity

Definitions & Structural Hierarchy[cite: 26, 27]

  • Uniform Continuity: $\forall\epsilon>0, \exists\delta>0, \forall x,y\in A (|x-y|<\delta\Rightarrow|f(x)-f(y)|<\epsilon)$[cite: 26].
    Distinction: In ordinary continuity, $\delta$ depends on both $\epsilon$ and the local location $x$[cite: 27]. In uniform continuity, one single $\delta$ works universally across the entire set $A$[cite: 27].
  • Lipschitz Continuity: $\exists L>0, \forall x,y\in A (|f(x)-f(y)|\le L|x-y|)$[cite: 27].
    Intuition: The steepness (secant slope) is strictly capped by a maximum speed $L$[cite: 27].
  • The Hierarchy: Lipschitz Continuous $\rightarrow$ Uniformly Continuous $\rightarrow$ Continuous[cite: 27].
Exercise 2.1: Lipschitz vs. Uniform Continuity[cite: 27]
Counterexample (Uniform $\not\rightarrow$ Lipschitz): Consider $f(x)=\sqrt{x}$ on $[0,1]$. It is continuous on a closed bounded set, hence uniformly continuous[cite: 27]. However, as $x\rightarrow0$, the slope $\frac{1}{\sqrt{x}}\rightarrow\infty$[cite: 27]. No finite constant $L$ exists to bound the ratio, so it is not Lipschitz[cite: 27].

3. The Bisection Method (Constructive Root-Finding)

Algorithmic Formulation[cite: 28]
Let $f:[a_0,b_0]\rightarrow\mathbb{R}$ be continuous with $f(a_0)<0$ and $f(b_0)>0$[cite: 28]. By the IVT, there exists a root $x^*\in(a_0,b_0)$ where $f(x^*)=0$[cite: 28].

Steps: Evaluate midpoint $x_n=\frac{a_n+b_n}{2}$[cite: 28].
  • If $f(x_n)=0$, the exact root is found[cite: 28].
  • If $f(x_n)<0$, set $a_{n+1}=x_n$ and $b_{n+1}=b_n$[cite: 28].
  • If $f(x_n)>0$, set $a_{n+1}=a_n$ and $b_{n+1}=x_n$[cite: 28].
Exercise 3.2: Predicting Bisection Steps[cite: 29]
Predict steps $n$ required to solve $x^2=2$ on $[1,2]$ to an accuracy of $10^{-4}$[cite: 29].
We require $\frac{b_0-a_0}{2^{n+1}}<10^{-4} \Rightarrow \frac{1}{2^{n+1}}<\frac{1}{10000} \Rightarrow 2^{n+1}>10000$[cite: 29]. Since $2^{13}=8192$ and $2^{14}=16384$, $n+1 \ge 14 \Rightarrow n \ge 13$ steps[cite: 29]. Exactly 13 iterations guarantee accuracy within 0.0001[cite: 29].
