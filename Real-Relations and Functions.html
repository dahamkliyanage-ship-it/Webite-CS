Relations and Functions

1. Relations: The Core Machinery

Definition: Let A, B be non-empty sets. A relation $P:A\rightarrow B$ is a non-empty subset of the Cartesian product $A\times B$.

Notation: To state that an input $x$ connects to an output $y$, we write any of the following interchangeably: $(x,y)\in P, P:x\mapsto y, x^{p}y, xPy,$ or $xP_{y}$.

The Four Associated Sets:

  • Domain (dom P): The entire starting set A.
  • Co-domain (codom P): The entire target set B.
  • Pre-range (preran P): The inputs that actually have arrows leaving them: $\{x\in A|(x,y)\in P\}$.
  • Range (ran P): The outputs that actually receive arrows: $\{y\in B|(x,y)\in P\}$.

Classification of Relations:

  • One-Many: An input splits into multiple outputs: $\exists x\in A$, $\exists y_{1},y_{2}\in B$ $((x, y_{1}), (x, y_{2}) \in P \wedge y_{1} \ne y_{2})$.
  • Many-One: Different inputs merge into the same output: $\exists x_{1},x_{2}\in A$, $\exists y\in B$ $((x_{1},y), (x_{2},y) \in P \wedge x_{1} \ne x_{2})$.
  • Many-Many: The relation is both one-many and many-one.
  • One-One (Injection): The relation is neither one-many nor many-one.
  • Everywhere-defined: No input is left unused ($dom~P = preran~P$, or $\forall x\in A \exists y\in B$ such that $(x,y)\in P$).
  • Onto (Surjection): Every target element is reached ($codom~P = ran~P$, or $\forall y\in B \exists x\in A$ such that $(x,y)\in P$).
  • Bijection: The relation is both one-one and onto.

Composition and Inverses

  • Composite Relation $(Q\circ P)$: If $P:A\rightarrow B$ and $Q:B\rightarrow C$ with $ran~P = preran~Q = S$, then:
    $Q\circ P = \{(x,z)|(x,y)\in P \wedge (y,z)\in Q, y\in S\}$.
    Here, $preran(Q\circ P) = preran~P$ and $ran(Q\circ P) = ran~Q$.
  • Inverse Relation $(P^{-1})$: Reverses every pair: $P^{-1} = \{(y,x)|(x,y)\in P\}$.
    Notice: $ran~P = preran~P^{-1}$ and $ran~P^{-1} = preran~P$.
  • Identity Compositions: $P^{-1}\circ P = I = \{(x,x)|x\in preran~P\}$ and $P\circ P^{-1} = I = \{(y,y)|y\in ran~P\}$. Written concisely: $P\circ P^{-1} = P^{-1}\circ P = I$.

Exercise 1.1: Define a relation $R:A\rightarrow B$ that is many-many, not onto, and not everywhere-defined. Find its range and pre-range.
Solution: Let $A=\{1,2,3\}$ and $B=\{a,b,c\}$. Choose $R=\{(1,a),(1,b),(2,a)\}$.
It is one-many (shares input 1) and many-one (shares output a), hence many-many.
$preran~R=\{1,2\} \ne A$ (not everywhere-defined).
$ran~R=\{a,b\} \ne B$ (not onto).

Exercise 1.4: Show that $(S\circ R)^{-1}=R^{-1}\circ S^{-1}$.
Proof: Let $(z,x)\in(S\circ R)^{-1} \Leftrightarrow (x,z)\in S\circ R$.
$\Leftrightarrow \exists y$ such that $(x,y)\in R \wedge (y,z)\in S$.
$\Leftrightarrow \exists y$ such that $(y,x)\in R^{-1} \wedge (z,y)\in S^{-1}$.
$\Leftrightarrow \exists y$ such that $(z,y)\in S^{-1} \wedge (y,x)\in R^{-1} \Leftrightarrow (z,x)\in R^{-1}\circ S^{-1}$.

2. Equivalence Relations & Partitions

Definition: A relation $R:A\rightarrow A$ is an equivalence relation iff it satisfies:

  • Reflexive: $\forall a\in A, (a,a)\in R$.
  • Symmetric: $\forall a,b\in A, (a,b)\in R \Rightarrow (b,a)\in R$.
  • Transitive: $\forall a,b,c\in A, (a,b)\in R \wedge (b,c)\in R \Rightarrow (a,c)\in R$.

Partitions: An equivalence relation breaks A into disjoint subsets called partitions (or equivalence classes). Every element belongs to exactly one partition, and elements in the same partition are related to each other.

Exercise 2.1: Let $A^{\prime}=\{a,b,c\}$ and $R=\{(a,a),(b,b),(c,c),(b,c),(c,b)\}$.
It is Reflexive, Symmetric, and Transitive on $A^{\prime}$.
Resulting Partitions: $\{a\}$ and $\{b, c\}$.

3. Functions & Real-Valued Functions

Definition of a Function: A relation $f:A\rightarrow B$ is a function when it is:

  • Everywhere-defined ($dom~f = preran~f$).
  • Not one-many.

This allows us to write $(x,y)\in f$ simply as $f(x)=y$.

  • Composition of Functions: If $f:A\rightarrow B$ is onto and $g:B\rightarrow C$ is a function, then $ran~f = B = preran~g$ so the composite $g\circ f:A\rightarrow C$ is allowed and is also a function. We write: $(g\circ f)(x)=g(f(x)) \forall x\in A$.
  • Invertible Functions: When f is a bijection, the inverse relation $f^{-1}$ is also a function and a bijection. Identity properties hold: $(f^{-1}\circ f)(x)=x, \forall x\in A$ and $(f\circ f^{-1})(y)=y, \forall y\in B$. Concise shorthand: $f\circ f^{-1} = f^{-1}\circ f = I$.
  • Real-Valued Function: When sets $A,B\subseteq\mathbb{R}, f$ is called a real-valued function.
  • Binary Operations: A binary operation on a set A is formally defined as a function $*:A\times A\rightarrow A$. We write $a*b$ to mean $*((a,b))$ for $a,b\in A$.

Function Exercises & Proofs

Exercise 3.2: Prove that the composition of two one-one functions is one-one.
Proof: Let $f:A\rightarrow B$ and $g:B\rightarrow C$ be one-one. Assume $(g\circ f)(x_{1}) = (g\circ f)(x_{2})$, which means $g(f(x_{1}))=g(f(x_{2}))$. Since g is one-one, its inputs must be equal: $f(x_{1})=f(x_{2})$. Since f is one-one, its inputs must be equal: $x_{1}=x_{2}$. Therefore, $g\circ f$ is one-one.

Exercise 3.4: Show that $f(x)=x^{2}$ is not one-one. Restrict its domain to define two inverse functions.
Solution: $f(-2)=(-2)^{2}=4$ and $f(2)=2^{2}=4$. Since distinct inputs yield the same output, f is not one-one.
Domain Restriction 1: Restrict to $x\in[0,\infty)$. The function is now one-one, giving inverse $f_{1}^{-1}(x)=\sqrt{x}$.
Domain Restriction 2: Restrict to $x\in(-\infty,0]$. The function is one-one, giving inverse $f_{2}^{-1}(x)=-\sqrt{x}$.

Exercise 3.6: Let $f(x)=\frac{1-x}{1+x}$ and $g(x)=4x(1-x)$.
Evaluating $f\circ g$:
$(f\circ g)(x) = f(g(x)) = \frac{1-4x(1-x)}{1+4x(1-x)} = \frac{1-4x+4x^{2}}{1+4x-4x^{2}} = \frac{(2x-1)^{2}}{1+4x-4x^{2}}$.
