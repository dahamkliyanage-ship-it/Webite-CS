Solving homogeneous systems

Consider the homogeneous system
$$ A_{m \times n}X_{n \times 1} = O_{m \times 1}. $$
In a homogeneous system, the matrix equation equals a zero vector $O_{m \times 1}$ instead of a constants vector $B$.
The Trivial Solution

It is easy to see that $X = O$ (where all variables equal zero) is always a solution for this system. Therefore, any homogeneous system is always consistent. This guaranteed solution $X = O$ is known as the trivial solution.
Rank Conditions for Solutions

Because the constant column is all zeros, augmenting the matrix with it does not change its rank. Thus, for a homogeneous system, $\text{Rank } A = \text{Rank}(A|O)$ is always true. The number of solutions depends on how the rank compares to $n$ (the number of variables):
  • If $\text{Rank } A = \text{Rank}(A|O) = n$ then the system has a unique solution, which is exclusively the trivial one ($X=O$).
  • If $\text{Rank } A = \text{Rank}(A|O) < n$ then the system has infinitely many solutions other than the trivial solution (these are called non-trivial solutions).
