TOPIC 04: MACHINE CODE & NUMBER SYSTEMS

Data Representation

At its core, a computer only does one thing: it works with data and information. Think of data as the raw ingredients in a kitchen, and the computer as the master chef. The machine takes in that raw data, processes it, and serves up a finished, organized meal — the information.

01. Terminology

Underneath all those complex graphics and calculations, the machine stores and retrieves everything using the simplest system possible: microscopic 2-state hardware devices.

It all boils down to the smallest unit of data imaginable — a switch that is either completely OFF (0) or entirely ON (1).

02. Units of Data

Before we can measure massive amounts of data, we need to look at the absolute smallest pieces of the puzzle.

BIT

The Bit — The Atom

The absolute smallest unit of data representation. "Bit" is a catchy abbreviation for Binary digit. Either a 0 or a 1 — nothing in between.

BYTE

The Byte — The Building Block

When you sequence exactly 8 bits together, you create a byte. In networking standards, this is often called an octet to keep things completely unambiguous.

For years, the tech world had a massive identity crisis over the word "kilobyte" (kB). Depending on who you asked, it meant two completely different things.

>> DO NOT CONFUSE
  • The Decimal Context: A kilobyte meant 1,000 (10³) bytes — the standard used for physical disk capacities and data transfer rates.
  • The Binary Context: A kilobyte meant 1,024 (2¹⁰) bytes — used for OS-specific memory and file sizes.

To fix this chaos, international standard bodies (ISO and IEC) officially split the naming conventions.

SI

SI Prefixes — Decimal (Powers of 10)

10³ bytes = kilobyte (kB), 10⁶ bytes = megabyte (MB), 10⁹ bytes = gigabyte (GB).

IEC

Binary Prefixes — Powers of 2

2¹⁰ bytes = kibibyte (KiB), 2²⁰ bytes = mebibyte (MiB), 2³⁰ bytes = gibibyte (GiB).

05. MSB & LSB

When you look at an 8-bit sequence (a byte), not all bits are created equal. The position of the digit completely determines its absolute power and mathematical weight.

>> THE HIERARCHY

Just like standard numbers, the digit on the far left carries the most value, and the one on the far right carries the least.

  • Most Significant Bit (MSB): The leftmost bit (Position 7). It dictates the largest chunk of the value, and in signed integers, controls the positive/negative sign.
  • Least Significant Bit (LSB): The rightmost bit (Position 0). It carries the smallest possible mathematical weight (2⁰ = 1).

06. Bit Constraints & Overflow

Computers store data in hardware registers, and the number of bits a register can hold is strictly limited. Here is what happens when you push the machine past its absolute limit.

>> SYSTEM OVERFLOW

If you add two numbers and the result is too big for the register to accommodate, the extra "carry bit" spills over the edge and is lost, causing a critical calculation error.

>> ANALOGY

Think of a register like a 1-litre water bottle. If you try to pour 1.5 litres into it, that extra half-litre spills over the top and is lost. In computing, that "spilled" extra bit is called the carry bit. When it falls off the edge, your computer stores the wrong number — which can crash your entire program.

08. Signed Integers & Two's Complement

How does a computer understand negative numbers if it only speaks in 1s and 0s? It uses a clever system called Two's Complement, where the exact representation is defined by the hardware's word size.

>> 1. THE NEGATIVE ZONE (MSB)

In a signed integer, the MSB completely controls the sign. If it is 0, the number is positive. If it is 1, the number is negative. The MSB acts as a massive negative weight: −2n−1.

>> 2. THE FLIP & ADD METHOD

Want to manually find the two's complement of a negative number (like −5)? Follow the standard hardware protocol.

1

Get the Positive Binary

Write +5 in an 8-bit register: 0000 0101

2

One's Complement — Flip the Bits

Swap every 0 to 1, and 1 to 0: 1111 1010

3

Add 1

Add 1 to the LSB to get your final −5: 1111 1011

LIMITS

The Boundary Formula

For an n-bit register, the smallest signed integer is −2n−1 (MSB=1, all others=0). The largest is 2n−1 − 1 (MSB=0, all others=1).

PYTHON

Python Execution

Python handles this automatically. Run ~0 (Bitwise NOT 0) and Python returns -1. Check its binary with bin(-2) and Python outputs -0b10.

09. Floating-Point Numbers

Integers are great for whole numbers, but what about real numbers with fractions? The machine uses Floating-Point Numbers — a system that approximates values to support a massive numerical range.

>> 1. THE ARCHITECTURE

Instead of fixing the decimal point in one place, the machine allows it to "float." It calculates the value using scientific notation:

Number = mantissa × baseexponent

  • Mantissa (Significand): A fixed number of the most significant digits.
  • Exponent: The scale that determines exactly where the decimal point floats.
>> 2. THE IEEE-754 STANDARD (32-BIT)

Computers slice up an allocated 32-bit register (Single-Precision) into three highly specific fields.

10. Non-Numeric Data

Computers are built to crunch numbers, but what happens when you need to store a name, a password, or a text message? Non-numeric data is primarily textual — letters (a–z, A–Z), digits (0–9), symbols (!, @, #), and control characters.

>> 1. THE ASCII STANDARD

ASCII (American Standard Code for Information Interchange) is the original cheat sheet — a standardized lookup table that maps every common character to a unique 7-bit binary number.
