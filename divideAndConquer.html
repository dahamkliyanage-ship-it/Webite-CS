Divide and Conquer

The phrase Divide and Conquer (or Divide et impera in Latin) is famously attributed to the Roman emperor Julius Caesar. What started as a brilliant military tactic for dismantling massive armies has evolved into one of the most powerful problem-solving paradigms in computer science to develop highly efficient algorithms for sorting, searching, and parsing.

01. The Three-Phase Paradigm

In computer science, this term is used to describe a problem-solving paradigm where a massive problem is recursively shattered into two or more sub-problems that are similar to the original. Here is the exact execution flow:

PHASE 1: DIVIDE

Break the problem into smaller sub-problems.

PHASE 2: CONQUER

Solve each sub-problem independently.

PHASE 3: COMBINE

Bring their solutions together to solve the original problem.

02. Quicksort Mechanics

Quicksort takes a chaotic array of values as input and completely outputs the sorted contents by utilizing a pivot mechanism.

>> THE PIVOT

First, a specific value in the array is selected to be the pivot element. There are multiple ways to choose this target (the leftmost element, the rightmost, the median, or even a random element).

>> THE PARTITION

The array is reordered. All values strictly less than the pivot are pushed before it, and all values greater than the pivot are placed after it. The pivot lands in its absolute correct final position.

>> THE RECURSIVE ASSAULT

Once the array is partitioned into two smaller sub-arrays around the pivot, steps 1 and 2 are recursively applied separately to the lower-value sub-array and the higher-value sub-array until the entire dataset is flawless.

Here is how you translate the pivot and partition logic into raw machine execution.

quicksort.py
def partition(arr, low, high):
    pivot = arr[high]
    i = (low - 1)

    for j in range(low, high):
        if arr[j] <= pivot:
            i = i + 1
            arr[i], arr[j] = arr[j], arr[i]

    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return (i + 1)

def quickSort(arr, low, high):
    if low < high:
        pidx = partition(arr, low, high)
        quickSort(arr, low, pidx - 1)
        quickSort(arr, pidx + 1, high)

arr = [10, 5, 7, 9, 1, 3]
n = len(arr)
quickSort(arr, 0, n - 1)
print("Sorted array is:", arr)

03. Mergesort

>> JOHN VON NEUMANN

Merge sort is another absolute heavyweight in the divide and conquer arena. It was engineered in 1945 by the legendary mathematician and physicist John von Neumann. Instead of using a pivot, he designed a system that systematically shatters the entire dataset into microscopic pieces before reassembling them flawlessly.

The entire algorithm relies on three strict, recurring actions. It aggressively splits the data until it hits rock bottom, and then strategically builds it back up.

PHASE 1: DIVIDE

Take your massive, unsorted list of n-items and aggressively divide it exactly in half, over and over, until you are left with n sub-lists that each contain only a single element.

PHASE 2: TERMINATE

This is the base case. A list containing only one single element is mathematically impossible to be out of order. It is inherently sorted. This triggers the termination of the division phase.

PHASE 3: MERGE

Now, shift into reverse. Repeatedly merge the sorted sub-lists back together, comparing elements as you go, to produce new, larger sorted lists until only one final sorted list remains.

Merge Sort Explanation

Here is how you translate von Neumann's logic into machine execution. Notice how the function first calls itself to handle the splitting, and then uses while loops to handle the final assembly.

mergesort.py
def mergeSort(arr):
    # Check if array is already sorted; a single element triggers the base case
    if len(arr) > 1:
        mid = len(arr) // 2

        # Divide the array into two halves
        left = arr[:mid]
        right = arr[mid:]

        # Recursively mergesort the left and right halves
        mergeSort(left)
        mergeSort(right)

        i = j = k = 0

        # Merge temporary arrays left[] and right[]
        while i < len(left) and j < len(right):
            if left[i] < right[j]:
                arr[k] = left[i]
                i += 1
            else:
                arr[k] = right[j]
                j += 1
            k += 1

        # Copy any remaining data
        while i < len(left):
            arr[k] = left[i]
            i += 1
            k += 1

        while j < len(right):
            arr[k] = right[j]
            j += 1
            k += 1

arr = [15, 11, 7, 5, 9, 13]
mergeSort(arr)
print("Final Sorted array: ", arr)

04. Karatsuba Algorithm

>> THE 1960 BREAKTHROUGH

Discovered by Russian mathematician Anatoly Alexeyevich Karatsuba, this algorithm provides a significantly faster method for multiplying massive numbers. The key observation? A two-digit multiplication can physically be done using only 3 operations instead of the 4 classically required. This massive reduction in processing load is achieved entirely through the Divide and Conquer paradigm.

To multiply two massive numbers, you slice them in half based on their base (m). Imagine multiplying two numbers structured as x1 · m + x2 and y1 · m + y2. Here is the exact execution flow:

1

Compute F

Multiply the first halves: x1 · y1 → F
2

Compute G

Multiply the second halves: x2 · y2 → G
3

Compute H

Add the halves, then multiply: (x1 + x2) · (y1 + y2) → H
4

Compute the K-Value

Subtract to find the middle term: H - F - G → K
5

The Final Assembly

Shift the values based on powers of m to get the final result. Because computing F, G, and H are all smaller multiplications, we trigger recursion to solve them.

Result = F · m2 + K · m + G
Karatsuba Explained

Here is how you translate Karatsuba's mathematical optimization into flawless machine execution.

karatsuba
def karatsuba(x, y):
    print("Calling karatsuba with", x, "and", y)

    # Terminal Condition (Base Case)
    if len(str(x)) < 3 or len(str(y)) < 3:
        return x * y

    # Calculate the splitting point
    n = max(len(str(x)), len(str(y))) // 2

    # Split the digit sequences
    x1 = x // 10**(n)
    x2 = x % 10**(n)
    y1 = y // 10**(n)
    y2 = y % 10**(n)

    # Recursive Calls
    F = karatsuba(x1, y1)
    G = karatsuba(x2, y2)
    H = karatsuba((x1 + x2), (y1 + y2))

    # Final Reassembly
    return ((10**(2*n)) * F) + ((10**n) * (H - F - G)) + G

# --- Driver Code ---
print(karatsuba(23, 45))
print(karatsuba(123456, 987654))
