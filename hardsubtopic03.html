03. MEMORY & STORAGE

Memory & Storage

Memory helps the CPU work with data quickly, while storage keeps data for long-term use. RAM and cache support active processing, while HDDs and SSDs provide persistent storage.

01. Memory vs Storage

Both memory and storage hold data, but they serve completely different purposes in the machine's architecture.

MEMORY

Active Processing

  • Used to hold data and instructions currently in use.
  • Incredibly fast access speeds.
  • Usually temporary (volatile).
  • Examples: RAM, Cache
STORAGE

Long-Term Retention

  • Keeps data safe even when the power is turned off.
  • Generally slower than memory.
  • Usually persistent (non-volatile).
  • Examples: HDD, SSD

02. Primary Memory: RAM & ROM

Volatile

RAM (Random Access Memory)

RAM is the computer's main working memory. It temporarily stores the programs and data currently being used by the CPU.

It is volatile, meaning its contents are completely lost when the computer is turned off. More RAM generally allows a computer to handle more programs and data at the same time.

Non-Volatile

ROM (Read-Only Memory)

ROM stores information that is intended to remain available even when the computer is powered down.

It is non-volatile, meaning its contents are retained without power. ROM is commonly associated with the vital instructions needed during the startup (booting) of a computer.

03. Cache Memory

Cache is a small amount of extremely fast memory located close to (or directly within) the CPU. It stores frequently used data and instructions so the CPU can access them without waiting on the slower Main Memory (RAM).

>> CACHE LEVELS

Cache is structured in levels: L1 → L2 → L3

Generally, L1 is the smallest and fastest (closest to the core), while L3 is larger but slightly slower.

04. Secondary Storage: HDD vs SSD

Storage is used to keep data and programs for long-term use. The two most common physical formats are Hard Disk Drives and Solid-State Drives.

HDD

Hard Disk Drive (Magnetic)

Stores data using magnetic disks (platters) that rotate mechanically.

  • Advantages: Massive storage capacities and a generally lower cost per gigabyte (GB).
  • Disadvantages: Slower data access speeds and contains fragile moving mechanical parts (read/write heads).
SSD

Solid-State Drive (Flash)

Stores data using flash memory chips and has absolutely zero moving mechanical parts.

  • Advantages: Significantly faster data access, incredibly fast boot/loading times, and much greater resistance to physical movement and drops.

05. The Memory Hierarchy

Computer memory can be viewed as a strict hierarchy based mainly on speed, physical size, and cost per byte. As we move down the pyramid, storage capacity generally increases, but access speed drops significantly.

Registers
← Fastest, Smallest
Cache (L1 / L2 / L3)
RAM (Main Memory)
Storage (HDD / SSD)
← Slowest, Largest
