02. COMPUTER HARDWARE

Hardware Architecture

Hardware provides the physical foundation of a computer system. The motherboard connects its components, the CPU processes instructions, and input/output devices allow the computer to interact with the outside world.

>> THE PHYSICAL LAYER

Hardware refers to the physical parts of a computer that you can see and touch. Hardware works together with software to perform tasks.

Examples: CPU, Motherboard, RAM, Storage devices, Keyboard, Monitor.

Watch & Learn: Computer Hardware

02. The Motherboard

The motherboard is the main circuit board that connects the different components of a computer. It allows components such as the CPU, memory, storage, and expansion devices to communicate with each other. Think of it as the main platform that brings the hardware together.

03. CPU — Central Processing Unit

The CPU is the main processing unit of a computer. It executes instructions and performs the operations needed to run programs.

Logic

ALU

The Arithmetic Logic Unit performs arithmetic operations (such as addition and subtraction) and logical operations (such as comparisons).

10 + 5 → Arithmetic
10 > 5 → Logical

Management

Control Unit

The CU manages the execution of instructions. It fetches instructions, decodes them, and controls the required operations. In simple terms, it directs the other parts of the CPU.

Workspace

Registers

Very small and fast storage locations inside the CPU. They temporarily hold data being processed, instructions, addresses, and intermediate results (e.g., Program Counter, Instruction Register).

>> THE INSTRUCTION CYCLE

The CPU processes instructions through a repeated cycle:

  • Fetch: Gets the next instruction from memory.
  • Decode: Determines what the instruction means.
  • Execute: Performs the required operation.

04. Input & Output Devices

INPUT

Sending Data

Input devices allow users to send data or instructions to a computer.

  • Keyboard: enters text and commands
  • Mouse: controls the pointer
  • Microphone: captures sound
  • Camera: captures images and video
  • Scanner: converts physical documents
OUTPUT

Presenting Data

Output devices present the processed information from a computer to the user.

  • Monitor: displays visual information
  • Printer: produces physical copies
  • Speakers: produce sound
  • Projector: displays on a larger surface
