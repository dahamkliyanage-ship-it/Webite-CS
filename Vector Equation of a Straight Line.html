Vector Equation of a Straight Line

In three-dimensional space, a line is completely determined if we know either:
1. One point on the line and the direction of the line.
2. Two distinct points on the line.
We will define vector equations for both of these scenarios.

The straight line that passes through the point $\underline{r_0} = (x_0, y_0, z_0)$ and parallel to the non zero vector $\underline{v} = a\underline{i} + b\underline{j} + c\underline{k}$


Figure 1: Vector equation of a line parallel to vector $\underline{v}$
Derivation of the Equation

Let $(x, y, z)$ be an arbitrary point on the straight line with the position vector $\underline{r}$.
Looking at Figure 1, the vector connecting our known point $\underline{r_0}$ to our arbitrary point $\underline{r}$ is $\underline{r} - \underline{r_0}$.

Because the line is parallel to the given direction vector $\underline{v}$, the vector $\underline{r} - \underline{r_0}$ must be a scalar multiple of $\underline{v}$. Thus, $\underline{r} - \underline{r_0} = t\underline{v}$ for some scalar parameter $t \in \mathbb{R}$.

Therefore, rearranging for $\underline{r}$ gives the parametric vector equation:
$$ \underline{r} = \underline{r_0} + t\underline{v} \quad \text{where } t \in \mathbb{R} $$

Symmetric Form

We can break this vector equation down into its individual $x$, $y$, and $z$ coordinates. If we substitute $\underline{r} = x\underline{i} + y\underline{j} + z\underline{k}$, $\underline{r_0} = x_0\underline{i} + y_0\underline{j} + z_0\underline{k}$, and $\underline{v} = a\underline{i} + b\underline{j} + c\underline{k}$ into the equation, we get the parametric equations:

$x = x_0 + at$
$y = y_0 + bt$
$z = z_0 + ct$

If we solve each of these three equations for the parameter $t$, and set them equal to each other, we obtain the symmetric form of the straight line:

$$ \frac{x - x_0}{a} = \frac{y - y_0}{b} = \frac{z - z_0}{c} $$
Detailed Example 1: Finding the Equation of a Line

Find the vector and symmetric equations of the line that passes through the point $P(2, -1, 4)$ and is parallel to the vector $\underline{v} = 3\underline{i} + 5\underline{j} - 2\underline{k}$.

Step 1: Identify $\underline{r_0}$ and $\underline{v}$.
  • The position vector of point P is $\underline{r_0} = 2\underline{i} - 1\underline{j} + 4\underline{k}$.
  • The direction vector is $\underline{v} = 3\underline{i} + 5\underline{j} - 2\underline{k}$.

Step 2: Write the Vector Parametric Equation ($\underline{r} = \underline{r_0} + t\underline{v}$).
$$ \underline{r} = (2\underline{i} - \underline{j} + 4\underline{k}) + t(3\underline{i} + 5\underline{j} - 2\underline{k}) $$

Step 3: Write the Symmetric Equations.
Using $(x_0, y_0, z_0) = (2, -1, 4)$ and direction ratios $(a, b, c) = (3, 5, -2)$:
$$ \frac{x - 2}{3} = \frac{y - (-1)}{5} = \frac{z - 4}{-2} \implies \frac{x - 2}{3} = \frac{y + 1}{5} = \frac{z - 4}{-2} $$


The straight line that passes through the points $A$ and $B$


Figure 2: Vector equation of a line passing through points A and B
Derivation of the Equation

Let $C$ be an arbitrary point on the line joining $A$ and $B$ with the position vector $\underline{r}$.
From Figure 2, the vector connecting points A and B is $\overrightarrow{AB} = \underline{r_2} - \underline{r_1}$. This acts as our direction vector $\underline{v}$ from the previous section.

Since $A, B$, and $C$ lie on the same straight line, the vector $\overrightarrow{AC}$ is a scalar multiple of $\overrightarrow{AB}$.
Then $\overrightarrow{AC} = t\overrightarrow{AB}$ for some scalar $t \in \mathbb{R}$.

Substituting the position vectors for these segments:
$$ \underline{r} - \underline{r_1} = t(\underline{r_2} - \underline{r_1}) $$ $$ \underline{r} = \underline{r_1} + t\underline{r_2} - t\underline{r_1} $$
Hence, factoring out $\underline{r_1}$ gives the vector equation:
$$ \underline{r} = (1 - t)\underline{r_1} + t\underline{r_2} \quad \text{where } t \in \mathbb{R} $$

Symmetric Form

Similar to section, if we plug in the coordinates for $A(x_1, y_1, z_1)$, $B(x_2, y_2, z_2)$, and arbitrary point $C(x, y, z)$, the direction ratios are $(x_2 - x_1), (y_2 - y_1), (z_2 - z_1)$. This gives the symmetric form:

$$ \frac{x - x_1}{x_2 - x_1} = \frac{y - y_1}{y_2 - y_1} = \frac{z - z_1}{z_2 - z_1} $$
Detailed Example 2: Line Through Two Points

Find the symmetric equation of the line passing through point $A(1, 0, -2)$ and point $B(3, 4, 1)$.

Step 1: Calculate the direction vector ($\overrightarrow{AB}$).
$$ \overrightarrow{AB} = (3 - 1)\underline{i} + (4 - 0)\underline{j} + (1 - (-2))\underline{k} = 2\underline{i} + 4\underline{j} + 3\underline{k} $$
The direction ratios are $(a, b, c) = (2, 4, 3)$.

Step 2: Use point $A$ and the direction vector to write the symmetric equation.
Using $(x_1, y_1, z_1) = (1, 0, -2)$:
$$ \frac{x - 1}{2} = \frac{y - 0}{4} = \frac{z - (-2)}{3} $$ $$ \frac{x - 1}{2} = \frac{y}{4} = \frac{z + 2}{3} $$
Note: You could also use the coordinates of point B as the numerators, and the equation would still represent the exact same line in 3D space.
