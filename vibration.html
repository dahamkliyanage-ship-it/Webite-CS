ME 1033: Mechanical Vibrations (SDoF Systems)

Free Undamped & Damped Oscillations, Damping Regimes, Equivalent Elements, and Torsional Dynamics

1. Undamped Free Vibrations (Mass-Spring Model)

Occurs when motion is maintained purely by gravitational or elastic restoring forces without energy dissipation.

Equation of Motion: m · ẍ + k · x = 0  →  ẍ + ω²x = 0
Natural Frequency: ω = √(k / m)  [rad/s]
Cyclic Frequency: fn = ω / (2π)  [Hz]
Periodic Time: T = 2π / ω = 1 / fn  [s]
General Solution: x(t) = A · cos(ωt - φ)
Quick Test: Static Deflection & Natural Frequency

A mass causes a static deflection of δst = 25 mm in a vertical spring. Taking g = 9.81 m/s², what is the natural frequency ω of the system?

Show Answer & Working

At static equilibrium: mg = k · δst → k/m = g / δst.

ω = √(g / δst) = √(9.81 / 0.025) = √(392.4) ≈ 19.81 rad/s (fn ≈ 3.15 Hz).

2. Damped Free Vibrations (Viscous Dashpot)

Mechanical resistance is modeled by a dashpot generating a damping force proportional to velocity (Fd = c · ẋ).

Differential Equation: m · ẍ + c · ẋ + k · x = 0
Standard Form: ẍ + 2βω · ẋ + ω²x = 0

Key Parameters:
Undamped Natural Frequency: ω = √(k / m)
Damping Ratio: β = c / (2mω) = c / (2√(mk))
Critical Damping Constant: cc = 2mω = 2√(mk)
Characteristic Equation: λ² + 2βωλ + ω² = 0 → λ1,2 = -βω ± ω√(β² - 1)

3. Damping Regimes (β)

The value of the damping ratio β dictates whether the system oscillates or returns aperiodically to rest.

  • Overdamped (β > 1): Two real, negative, distinct roots. Non-oscillatory; the mass slowly crawls back to equilibrium.
    x(t) = A1eλ1t + A2eλ2t
  • Critically Damped (β = 1): Two equal negative roots (λ = -ω). Returns to equilibrium in the shortest possible time without oscillating.
    x(t) = (A1 + A2t) · e-ωt  [c = 2√(mk)]
  • Underdamped (β < 1): Complex conjugate roots. Generates true oscillatory motion with exponentially decaying amplitude envelope.
    Damped Angular Frequency: ωd = ω√(1 - β²)
    Damped Periodic Time: Td = 2π / ωd = 2π / (ω√(1 - β²))
    Response: x(t) = A · e-βωt · cos(ωdt - φ)
Quick Test: Car Suspension Damping Shift (Lecture 6 Problem 4)

A 1300 kg sports car deflects 0.05 m under its own weight and is designed for critical damping (β = 1). If 4 passengers (65 kg each) enter the car, what is the new damping ratio β?

Show Answer & Working

1. Stiffness: k = mg / δ0 = (1300 × 9.81) / 0.05 = 255.06 × 10³ N/m.

2. Designed c: c = 2√(mk) = 2√(1300 × 255060) ≈ 36,420 Ns/m.

3. New mass: mnew = 1300 + 4(65) = 1560 kg.

4. New β: β = c / [2√(mnewk)] = 36420 / [2√(1560 × 255060)] = 0.913 (< 1, shifts to underdamped).

4. Logarithmic Decrement (δ)

Quantifies the rate of amplitude decay over successive cycles in underdamped systems.

Between Consecutive Peaks: δ = ln(ar / ar+1) = (2πβ) / √(1 - β²)
Amplitude Ratio: ar / ar+1 = e[(2πβ) / √(1 - β²)]

Across n Cycles (From peak 1 to peak n):
ln(a1 / an) = [2(n - 1)πβ] / √(1 - β²)
Quick Test: Amplitude Decay Calculation

In a vibrating machine system, the amplitude drops from 24.6 mm to 4.1 mm over 2 complete cycles (n = 3). Calculate the damping ratio β.

Show Answer & Working

Ratio a1 / a3 = 24.6 / 4.1 = 6.

ln(6) = 1.7918 = [2(3 - 1)πβ] / √(1 - β²) = (4πβ) / √(1 - β²).

Let Λ = 1.7918 / (4π) = 0.14258 → β = Λ / √(1 + Λ²) ≈ 0.1412.

5. Equivalent Springs and Dampers (Series & Parallel)

Simplifies multi-element elastic and damping networks into a single effective SDoF parameter.

Series Connection (Same force, displacements add):
1 / keq = 1 / k1 + 1 / k2  →  keq = (k1 · k2) / (k1 + k2)
1 / ceq = 1 / c1 + 1 / c2  →  ceq = (c1 · c2) / (c1 + c2)

Parallel Connection (Same displacement, forces add):
keq = k1 + k2 + ... + kn
ceq = c1 + c2 + ... + cn

Quick Test: Rubber & Felt Layers in Series (Lecture 6 Problem 1)

A 150 kg machine rests on a rubber layer (kr = 15 N/mm, cr = 600 Ns/m) and a felt layer (kf = 20 N/mm). If the equivalent damping constant ceq = 320.2 Ns/m, find the damping constant of the felt layer cf.

Show Answer & Working

Because layers are stacked, they behave in series:

1 / ceq = 1 / cr + 1 / cf → 1 / 320.2 = 1 / 600 + 1 / cf.

1 / cf = 0.003123 - 0.001667 = 0.001456 → cf ≈ 686.6 Ns/m.

6. Torsional Vibrations (Angular SDoF)

Angular oscillation of a rotor or arm about a fixed axis under torsional stiffness and damping.

Dynamic Equilibrium: JO · θ̈ + ct · θ̇ + kt · θ = 0
Standard Form: θ̈ + 2βω · θ̇ + ω²θ = 0

Parameters:
Torsional Natural Frequency: ω = √(kt / JO)
Torsional Damping Ratio: β = ct / (2√(kt · JO))
Total Mass Moment: JO = IO,body + M · L²  [if carrying point mass M at length L]

Quick Test: Robot Arm Torsional Critical Damping (Lecture 6 Q23)

A robot arm (IO = 1.2 kg·m², length L = 0.5 m) holds a load M = 6 kg and has torsional spring kt = 1000 Nm/rad. Determine the torsional damping constant ct required for critical damping (β = 1).

Show Answer & Working

1. Total moment of inertia about O: JO = IO + M · L² = 1.2 + 6(0.5)² = 1.2 + 1.5 = 2.7 kg·m².

2. Critical damping condition (β = 1): ct = 2√(kt · JO).

ct = 2√(1000 × 2.7) = 2√(2700) = 2 × 51.96 ≈ 103.92 Ns·m/rad.
