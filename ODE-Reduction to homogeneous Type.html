Reduction to Homogeneous Type

The General Form

The equation of the form
$$ \frac{dy}{dx} = \frac{ax + by + c}{Ax + By + C} $$
can be reduced to a homogeneous form by changing the variables $x, y$ to $X, Y$ related by the equations:
$$ x = X + h, \quad y = Y + k $$
where $h, k$ are constants to be chosen so as to make the given equation homogeneous.
Applying the Substitution

Substituting $x = X + h$ and $y = Y + k$, the differentials become $dx = dX$ and $dy = dY$. The given equation becomes:
$$ \frac{dY}{dX} = \frac{a(X+h) + b(Y+k) + c}{A(X+h) + B(Y+k) + C} $$ $$ \frac{dY}{dX} = \frac{aX + bY + (ah + bk + c)}{AX + BY + (Ah + Bk + C)} $$
Now, let's select $h$ and $k$ such that the constant terms vanish:
$$ ah + bk + c = 0 $$ $$ Ah + Bk + C = 0 $$
Solving this system of linear equations gives us the values for $h$ and $k$. Once applied, the differential equation simplifies to:
$$ \frac{dY}{dX} = \frac{aX + bY}{AX + BY} $$
This is now a standard homogeneous equation in variables $X$ and $Y$. Now apply the previous method (substituting $Y = vX$) to find the solution.
Worked Example: Reduction Process

Reduce the equation $\frac{dy}{dx} = \frac{y - x + 1}{y + x + 5}$ to a homogeneous form.

Step 1: Set up the translation.
Let $x = X + h$ and $y = Y + k$. Then $dx = dX$ and $dy = dY$.
$$ \frac{dY}{dX} = \frac{(Y+k) - (X+h) + 1}{(Y+k) + (X+h) + 5} = \frac{Y - X + (k - h + 1)}{Y + X + (k + h + 5)} $$

Step 2: Solve for $h$ and $k$.
Set the constant parts to zero to force homogeneity:
$-h + k + 1 = 0 \quad$ (1)
$h + k + 5 = 0 \quad$ (2)
Adding the two equations: $2k + 6 = 0 \implies k = -3$.
Substituting $k=-3$ into (2): $h - 3 + 5 = 0 \implies h = -2$.

Step 3: Write the reduced homogeneous equation.
With $h=-2$ and $k=-3$, the constants disappear, leaving:
$$ \frac{dY}{dX} = \frac{Y - X}{Y + X} $$
This equation can now be solved using the substitution $Y = vX$. Once solved for $X$ and $Y$, you must substitute back $X = x - h = x + 2$ and $Y = y - k = y + 3$ to get the final answer in terms of $x$ and $y$.
