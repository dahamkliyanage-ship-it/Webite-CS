Sequences & Convergence

1. Sequence Definition & Formal Limits

  • Sequence: A sequence is a function $u:\mathbb{Z}^{+}\rightarrow\mathbb{R}$. We write the image of n as $u_{n}$ instead of $u(n)$.
  • Finite Limit of a Sequence:
    $lim_{n\rightarrow\infty}u_{n}=L\in\mathbb{R}\Leftrightarrow\forall\epsilon>0, \exists N\in\mathbb{Z}^{+}, \forall n (n>N\Rightarrow\vert{}u_{n}-L\vert{}<\epsilon)$.
    Plain Meaning: For any precision $\epsilon>0$, there exists an index cutoff N past which every single term $u_{n}$ is within $\epsilon$ of L.
  • Divergence to $\pm\infty$:
    $lim_{n\rightarrow\infty}u_{n}=\infty\Leftrightarrow\forall M>0, \exists N\in\mathbb{Z}^{+}, \forall n (n>N\Rightarrow u_{n}>M)$.
    $lim_{n\rightarrow\infty}u_{n}=-\infty\Leftrightarrow\forall M<0, \exists N\in\mathbb{Z}^{+}, \forall n (n>N\Rightarrow u_{n}

If a sequence does not approach a finite L, $\infty$, or $-\infty$, its limit does not exist (DNE).

One-Sided Limits & Basic Proofs

  • Converging from above ($L^{+}$): $\forall\epsilon>0, \exists N\in\mathbb{Z}^{+}, \forall n (n>N\Rightarrow 0\le u_{n}-L<\epsilon)$.
  • Converging from below ($L^{-}$): $\forall\epsilon>0, \exists N\in\mathbb{Z}^{+}, \forall n (n>N\Rightarrow -\epsilon

If $u_{n}\rightarrow L^{+}$ or $u_{n}\rightarrow L^{-}$, then $lim_{n\rightarrow\infty}u_{n}=L$.

Exercise 1.1: Prove $lim_{n\rightarrow\infty}(1+\frac{1}{n})=1$.
Proof: Let $\epsilon>0$. By the Archimedean Property, choose $N>\frac{1}{\epsilon}$. For all $n>N$, $\frac{1}{n}<\epsilon$.
Thus: $\vert{}(1+\frac{1}{n})-1\vert{}=\vert{}\frac{1}{n}\vert{}=\frac{1}{n}<\epsilon$. Furthermore, since $u_{n}-1=\frac{1}{n}>0$, it converges from above: $1^{+}$.

Exercise 1.2: Prove $lim_{n\rightarrow\infty}n^{2}=\infty$.
Proof: Let $M>0$. Choose $N\ge\lceil\sqrt{M}\rceil$. For all $n>N, n>\sqrt{M}\Rightarrow n^{2}>M$. By definition, it diverges to $\infty$.

2. Limit Theorems & Arithmetic of Limits

A sequence $u_{n}$ is convergent iff $lim_{n\rightarrow\infty}u_{n}=L\in\mathbb{R}$. Otherwise, it is divergent.

  • If $u_{n}\rightarrow U$ and $v_{n}\rightarrow V$, then $lim(u_{n}+v_{n}) = U+V$. (Proven using the Triangle Inequality: $\vert{}(u_{n}+v_{n})-(U+V)\vert{} \le \vert{}u_{n}-U\vert{} + \vert{}v_{n}-V\vert{}$).
  • If $u_{n}\rightarrow U$ and $v_{n}\rightarrow V$, then $lim(u_{n}v_{n}) = UV$. (Relies on converging sequences being bounded).

Why $\infty-\infty$ is indeterminate: The limit depends on relative rates of growth. For example, if $u_{n}=n^{2}, v_{n}=n$, the limit is $\infty$. If $u_{n}=n, v_{n}=n^{2}$, the limit is $-\infty$. If $u_{n}=n+c, v_{n}=n$, the limit is $c$. Because no single consistent output can be defined, it is an indeterminate form.

3. Monotonic Sequences & Bounded Convergence

  • Increasing: $\forall m,n\in\mathbb{Z}^{+}, n>m\Rightarrow u_{n}\ge u_{m}$ (strictly increasing if $>$).
  • Decreasing: $\forall m,n\in\mathbb{Z}^{+}, n>m\Rightarrow u_{n}\le u_{m}$ (strictly decreasing if $<$).

A sequence is monotonic if it is either increasing or decreasing.

Bounded Convergence Theorem (Monotone Convergence Theorem):

  1. An increasing sequence $u_{n}$ that is bounded above converges to $sup\{u_{n}\}$ from below.
  2. A decreasing sequence $u_{n}$ that is bounded below converges to $inf\{u_{n}\}$ from above.

Theorem: Every converging sequence is bounded.

Advanced Convergence Exercises

Exercise 3.1: Examine $u_{n}=(-1)^{n}$ and $u_{n}=sin~n$.
$u_{n}=(-1)^{n}$ oscillates between -1 and 1. It diverges by oscillation. $u_{n}=sin~n$ never settles to any single real value on $[-1,1]$, thus it diverges.

Exercise 3.2: Solve Babylonian Square Root Algorithm $u_{n+1}=\frac{1}{2}(u_{n}+\frac{a}{u_{n}})$, $a>0, u_{1}>0$.
1. Lower Bound via AM-GM Inequality gives $u_{n} \ge \sqrt{a}$.
2. Monotonicity check shows $u_{n+1}-u_{n} \le 0$, so it is monotonically decreasing.
3. By the Bounded Convergence Theorem, it converges to limit L. Taking limits: $L = \frac{1}{2}(L+\frac{a}{L}) \Rightarrow L^{2}=a \Rightarrow L=\sqrt{a}$.

Exercise 3.3: Solve $u_{n+2}=\frac{1}{2}(u_{n+1}+u_{n})$ with $u_{1}=a, u_{2}=b$.
Let $d_{n}=u_{n+1}-u_{n}$. This forms a geometric sequence $d_{n}=(b-a)(-\frac{1}{2})^{n-1}$.
Using a telescoping sum and evaluating the limit as $n\rightarrow\infty$, the sum evaluates to $\frac{2}{3}$, and the sequence converges to $\frac{a+2b}{3}$.
