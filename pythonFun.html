The Scenario: An engineering lab is testing a motor, and the temperature sensor outputs a list of readings with occasional hardware glitches (impossible negative numbers or extreme spikes).

The Task: Write a function that takes a list of raw float readings. Use iteration and conditional logic to filter out temperatures below 0.0 or above 150.0. Return a dictionary containing the maximum, minimum, and average temperatures of the clean dataset.

Test Case 2 (Edge Case - All Glitches): Input: [-10.0, 155.5, -2.2] Output: None
Test Case 3 (Boundary Values): Input: [150.0, 0.0, 75.0] Output: {'max': 150.0, 'min': 0.0, 'avg': 75.0}

def clean_sensor_data(readings):
    clean_data = []
    for temp in readings:
        if 0.0 <= temp <= 150.0:
            clean_data.append(temp)
            
    if not clean_data:
        return None
        
    return {
        'max': max(clean_data),
        'min': min(clean_data),
        'avg': sum(clean_data) / len(clean_data)
    }

2. The Rocket Trajectory Simulator

The Scenario: You are testing a small model rocket and need to map its flight path over time.

The Task: Write a program that calculates the rocket's height using the formula (y = velocity * time - 0.5 * 9.8 * time^2). Use a while loop that calculates the height every 1 second, automatically breaking when it hits the ground (height drops below 0). Store every time-and-height pair as a tuple inside a master list and return the list.

Test Case 1 (Standard Launch): Input Velocity: 25 m/s Output: [(0, 0.0), (1, 20.1), (2, 30.4), (3, 30.9), (4, 21.6), (5, 2.5)]
Test Case 2 (Low Power Launch): Input Velocity: 10 m/s Output: [(0, 0.0), (1, 5.1), (2, 0.4)]
Test Case 3 (Dud Engine / Zero Velocity): Input Velocity: 0 m/s Output: [(0, 0.0)]

def simulate_rocket(velocity):
    trajectory = []
    time = 0
    while True:
        height = (velocity * time) - (0.5 * 9.8 * (time ** 2))
        if height < 0:
            break
        trajectory.append((time, round(height, 1)))
        time += 1
    return trajectory
iniVel=float(input("Enter the initial velocity: "))
print(simulate_rocket(iniVel))

def analyze_logs(filename):
    error_counts = {}
    try:
        with open(filename, 'r') as file:
            for line in file:
                code = line.strip()
                if code: # Skip empty lines
                    error_counts[code] = error_counts.get(code, 0) + 1
                
        if error_counts:
            top_error = max(error_counts, key=error_counts.get)
            return f"Most frequent error: {top_error}"
        return "Log file is empty."
        
    except FileNotFoundError:
        return "CRITICAL: Log file not found!"
