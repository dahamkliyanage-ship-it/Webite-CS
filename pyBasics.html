PHASE 1

Environment, Syntax & Basics

Python is designed to be simple to read and easy to write, but before building programs, you need to understand the environment in which Python runs and the basic rules that make up the language. This phase covers the essential foundations—from setting up your environment to working with basic collections.

01. The Python Environment

Python code needs an environment in which it can be written and executed. At the core of this environment is the Python interpreter, which reads Python code and executes it. You can interact with Python directly through the Python Shell:

python shell
>>> 5 + 38
>>> print("Hello, Python!")
Hello, Python!
>> CODE EDITORS & IDES

For larger programs, Python code is usually written in a file with the .py extension. While a simple text editor works, IDEs like VS Code, PyCharm, and IDLE provide syntax highlighting, debugging, and code completion. Python also supports virtual environments so each project maintains its own dependencies.

02. Python Syntax

Syntax refers to the rules that determine how Python code must be written. One of Python's most distinctive features is its use of indentation to define blocks of code (unlike languages that use {}). This makes properly formatted code an essential part of writing Python.

indentation
if age >= 18:
    print("You are an adult.")
>> COMMENTS

Comments allow programmers to leave notes inside their code using the # symbol. They are ignored when the program runs. Good comments explain why something is being done, not just what is obvious.

03. Variables & Dynamic Typing

A variable is a name that refers to a value. Python does not require you to declare the variable's type beforehand. The type is determined automatically from the value assigned to it, a concept known as dynamic typing.

variables
name = "Alex"
score = 95

# Dynamic Typing in action:
age = 20
age = "twenty"

04. Core Data Types

Every value in Python has a data type that determines what kind of data it represents. You can determine the type of a value using the type() function.

NUMBERS

Integers: Whole numbers (e.g., age = 20)
Floats: Decimals (e.g., price = 99.99)

TEXT & LOGIC

Strings: Text in quotes (e.g., name = "Alex")
Booleans: Logical True or False

NONE TYPE

None: Represents the intentional absence of a value (e.g., result = None).

05. Type Conversion

Sometimes data needs to be converted from one type to another. Python provides built-in functions like int(), float(), str(), and bool() for common conversions. This is especially important when working with user input, because input() always returns data as a string.

06. Operators

Operators allow Python to perform calculations, comparisons, and logical operations.

  • Arithmetic: + (Add), - (Subtract), * (Multiply), / (Divide), // (Floor Division), % (Remainder), ** (Power)
  • Comparison: ==, !=, >, <, >=, <=
  • Logical: and, or, not

07. Input and Output

Programs often need to receive information from users and display results. The print() function produces output, while input() receives it.

io_basis
name = input("Enter your name: ")
print("Hello", name)

# Remember to cast numerical input!
age = int(input("Enter your age: "))

08. Strings

A string is a sequence of characters used to represent text. Python uses zero-based indexing, meaning the first character is at index 0. They can be sliced using [start:end] and manipulated using built-in methods like .upper(), .strip(), and .replace().

>> F-STRINGS

f-strings provide an incredibly convenient way to combine text directly with variables without messy concatenation:
print(f"My name is {name} and I am {age}.")

09. Basic Collections

Python provides several built-in ways to store collections of values. These form the foundation for organizing and manipulating data.

LISTS & TUPLES

Lists: Dynamically sized, heterogeneous arrays. [10, "Python", True]
Tuples: Similar to a list, but strictly immutable. (10, 20)

SETS & DICTIONARIES

Sets: Stores unique, unordered values. {1, 2, 3}
Dicts: Stores fast-lookup key-value pairs. {"name": "Alex"}

10. Putting the Basics Together

The real purpose of learning syntax and basic features is to combine them into meaningful programs. This small program combines variables, inputs, type conversion, conditional operators, and f-strings.

grading_system
name = input("Enter your name: ")
mark = int(input("Enter your mark: "))

if mark >= 50:
    result = "Pass"
else:
    result = "Fail"

print(f"{name}: {result}")
