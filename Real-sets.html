Set Theory

1. Why Set Theory? & What is a Set?

A set is simply a container with a strict boundary, providing clear mathematical containers so that when we define collections of numbers, we know precisely what belongs inside and what stays outside without ambiguity.

  • A set is a well-defined collection of distinct objects called elements.
  • We write $x \in A$ if x is an element of set A, and $x \notin A$ if x is not an element of set A.
  • Rule: Elements are never repeated in a set (e.g., $\{1, 2, 2, 3\} = \{1, 2, 3\}$).
  • Axiomatic Grounding: Modern mathematics uses the Zermelo-Fraenkel set theory with the Axiom of Choice (ZFC, a system of 9 formal rules) to construct sets rigorously and avoid contradictions.

2. Core Definitions & Operations

Operation / Term Notation Formal Definition Everyday Meaning
Empty / Null Set $\emptyset$ or $\{\}$ Set with no elements An empty box.
Universal Set $S$ All elements under consideration The entire space you are working in.
Complement $A^c$ $x \in A^c \Leftrightarrow x \notin A$ Everything outside of A.
Union $A \cup B$ $x \in A \cup B \Leftrightarrow x \in A \vee x \in B$ Elements in A, in B, or in both.
Intersection $A \cap B$ $x \in A \cap B \Leftrightarrow x \in A \wedge x \in B$ Only elements shared by both A and B.
Subset $A \subset B$ $\forall x (x \in A \Rightarrow x \in B)$ Every item in A is also inside B.
Set Equality $A = B$ $(A \subset B) \wedge (B \subset A)$ A and B contain the exact same items.
Set Difference $A - B$ $A \cap B^c = \{x | x \in A \wedge x \notin B\}$ Elements of A with anything from B taken out.

3. Ordered Pairs, Cartesian Products & Power Sets

  • Ordered Pair $(x, y)$: Formally defined as $\{\{x\}, \{x, y\}\}$. This definition forces order so that $(a, b) = (c, d)$ if and only if $a = c$ and $b = d$.
  • Cartesian Product $(A \times B)$: The set of all ordered pairs where the first element is from A and the second is from B: $A \times B = \{(x, y) | x \in A, y \in B\}$.
  • Cardinality $(|A|)$: The total count of elements in A.
    • For Cartesian products: $|A \times B| = |A| \cdot |B|$.
    • Principle of Inclusion-Exclusion: $|A \cup B| = |A| + |B| - |A \cap B|$.
  • Power Set $(\mathcal{P}(A))$: The set of all possible subsets of A. If a set has $n$ elements $(|A| = n)$, its power set has $2^n$ subsets $(\vert{}\mathcal{P}(A)\vert{} = 2^{|A|})$.
    Example: If $A = \{1, 2\}$, then $\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\}$.

4. Not Everything Can Be a Set: Russell's Paradox

In naive set theory, people assumed any collection defined by words is a valid set. Consider the collection: $A = \{x | x \notin x\}$ (The collection of all sets that do not contain themselves).

The Fatal Trap: Ask: Is $A \in A$?

  • If Yes $(A \in A)$, then by definition A must satisfy the rule, meaning $A \notin A$ (Contradiction).
  • If No $(A \notin A)$, then by definition it satisfies the membership condition, so $A \in A$ (Contradiction).

Conclusion: A cannot exist as a set. This paradox is why mathematics requires formal rules (ZFC axioms) rather than unrestricted definitions.

5. Simple Proof Walkthroughs

Proof 1: De Morgan's Law for Sets, $(A \cup B)^c = A^c \cap B^c$
$x \in (A \cup B)^c \Leftrightarrow x \notin (A \cup B) \Leftrightarrow \sim(x \in A \vee x \in B)$
$\Leftrightarrow \sim(x \in A) \wedge \sim(x \in B)$ (by logic De Morgan's)
$\Leftrightarrow x \in A^c \wedge x \in B^c \Leftrightarrow x \in (A^c \cap B^c)$.

Proof 2: $A \cap B = A - (A - B)$
By definition of difference, $A - B = A \cap B^c$.
Then $A - (A - B) = A \cap (A \cap B^c)^c$.
Apply De Morgan's: $(A \cap B^c)^c = A^c \cup (B^c)^c = A^c \cup B$.
Distribute: $A \cap (A^c \cup B) = (A \cap A^c) \cup (A \cap B) = \emptyset \cup (A \cap B) = A \cap B$.

Proof 3: $A \subset A \cup B$
To show $A \subset A \cup B$, prove $\forall x (x \in A \Rightarrow x \in A \cup B)$:
Let $x \in A$. If proposition $p$ is True, then $p \vee q$ is True ($p \Rightarrow p \vee q$).
Therefore: $x \in A \Rightarrow (x \in A \vee x \in B)$.
By definition of union, this means $x \in A \Rightarrow x \in A \cup B$.

Proof 4: Ordered Pairs $(a,b) = (c,d) \Leftrightarrow a=c \text{ and } b=d$
Definition: $(x,y) = \{\{x\}, \{x,y\}\}$.
If $a \ne b$, $\{\{a\}, \{a,b\}\}$ contains a singleton $\{a\}$ and a two-element set $\{a,b\}$.
For equality $\{\{a\}, \{a,b\}\} = \{\{c\}, \{c,d\}\}$, the singletons must match ($\{a\} = \{c\} \Rightarrow a=c$) and the two-element sets must match ($\{a,b\} = \{c,d\}$).
Substitute $a=c$ into $\{a,b\} = \{a,d\}$. Since $b \in \{a,d\}$ and $b \ne a$, it must be that $b=d$.

Proof 5: Cartesian Product $|A \times B| = |A| \cdot |B|$
Partition $A \times B$ into distinct groups based on the first coordinate: $S_i = \{(a_i, b) | b \in B\}$.
For each $a_i \in A$, there are exactly $n$ distinct choices for $b \in B$, so $|S_i| = |B|$.
Summing over all $m$ disjoint sets gives: $|A \times B| = \sum |S_i| = m \cdot n = |A| \cdot |B|$.
