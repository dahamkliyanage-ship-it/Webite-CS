04. SOFTWARE & OS

Software & Systems

Software is a collection of programs and instructions that tells computer hardware what to do. Unlike hardware, software has no physical form.

>> THE INSTRUCTION LAYER

Software bridges the gap between human intent and machine execution. It can be broadly divided into two main categories: System Software and Application Software.

02. System vs Application Software

SYSTEM

Managing the Machine

System software manages and controls the computer's hardware and provides a platform for other software to run. It works mainly in the background, helping the computer operate properly.

  • Operating systems
  • Device drivers
  • Utility programs
APPLICATION

Performing Tasks

Application software is designed to help users perform specific tasks. Unlike system software, application software is mainly focused on what the user wants to accomplish.

  • Web browsers & Word processors
  • Media players & Image editors
  • Video games

03. Operating Systems (OS)

An Operating System is the main system software that manages the computer's hardware and software resources. It provides a vital interface between the user, applications, and the hardware.

What does an OS actually do?

Tasks

Processes

Running programs and managing concurrent tasks.

Storage

Memory

Allocating RAM and memory space to active programs.

Data

Files

Organizing, saving, and managing raw data.

Hardware

Devices

Communicating directly with physical hardware and peripherals.

Interaction

User Interface

Allowing users to visually or textually interact with the computer (e.g., Windows, macOS, Linux, Android, iOS).

>> KEY IDEA

System software manages the computer, while application software helps users perform tasks. The operating system connects the two by managing hardware resources and providing a platform for applications to run.
