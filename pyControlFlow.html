PHASE 2

Control Flow & Logic

A program doesn't have to execute every instruction from top to bottom. Real programs need to make decisions, repeat tasks, and change their behavior based on different conditions. Using conditions, loops, and logical operators, we can control which instructions run, when they run, and how often they run.

01. Making Decisions with if

The if statement allows a program to execute a block of code only when a condition is True. If the condition is false, the indented block is simply skipped. This gives programs their first form of decision-making: If something is true, do something.

if_statement.py
age = 20

if age >= 18:
    print("You are an adult.")

02. else & elif — Multiple Paths

Sometimes a program needs to choose between multiple possible paths. The else block runs when the if condition is false. For more than two possibilities, Python uses elif to check additional conditions sequentially from top to bottom.

else_path.py
age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")
elif_chain.py
mark = 72

if mark >= 75:
    grade = "A"
elif mark >= 65:
    grade = "B"
else:
    grade = "F"

03. Combining Conditions & Truthiness

Conditions can be combined using logical operators (and, or, not). Additionally, Python evaluates many values as either "truthy" or "falsy" directly, allowing for concise conditional checks without explicit comparisons.

and / or / not

if age >= 18 and has_id:
  print("Granted")

if not logged_in:
  print("Log in.")

FALSY VALUES

An empty string, zero, or empty collection evaluates to False.

  • False, None
  • 0, ""
  • [], {}
TRUTHINESS IN ACTION

name = ""
if not name:
  print("Empty.")

04. The for Loop & range()

Programs often perform the same operation multiple times. A for loop iterates through a sequence of values (like a list or string). When the number of repetitions is known, the range() function generates the sequence.

for_loops.py
# Iterating through a list
numbers = [10, 20, 30]
for number in numbers:
    print(number)

# Generating sequences with range(start, stop, step)
for i in range(2, 11, 2):
    print(i) # Outputs 2, 4, 6, 8, 10

05. The while Loop & Control Statements

A while loop executes as long as its condition remains true, making it useful when the repetition count is unknown. Python also provides break, continue, and pass to change how any loop behaves dynamically.

>> LOOP CONTROLS
  • break: Immediately stops and exits the loop entirely.
  • continue: Skips the current iteration and jumps to the next one.
  • pass: Does nothing. Acts as a syntactic placeholder.
while_control.py
count = 1
while count <= 5:
    if count == 3:
        count += 1
        continue # Skips printing 3
    print(count)
    count += 1

06. Nested Logic & Combined Flows

The real power of control flow comes from combining components. You can place conditions inside conditions (nested if), loops inside loops (nested loops for grids), or process collections by making decisions on every element.

combined_flow.py
numbers = [12, 7, 20, 5, 18]

# Combining a for loop with selection logic
for number in numbers:
    if number >= 10:
        print(number) # Prints 12, 20, 18

07. Conditional Expressions & Pattern Matching

Python provides modern shortcuts for cleaner code. Conditional expressions (ternary operators) condense simple if-else blocks into one line, while match statements handle multi-way decisions beautifully.

ternary.py
# Condensed conditional expression
age = 20
status = "Adult" if age >= 18 else "Minor"
match_case.py
command = "start"

match command:
    case "start":
        print("Starting...")
    case _:
        print("Unknown.")
