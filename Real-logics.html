Mathematical Logic & Proof Machinery

1. Why Do We Need Logic & Propositions?

In mathematics, we cannot leave room for guessing; logic is a strict set of rules that stops you from making false claims and ensures conclusions are 100% airtight.

What is a Proposition?
A proposition is a clear, unambiguous statement that is either True (T) or False (F), but never both at the same time.

  • Propositions: "Colombo is in Sri Lanka." (True). $2+2=5$ (False).
  • Non-propositions: "Is it raining?" (Question). "Clean your room!" (Command). $x+2=5$ (Unknown variable).

2. Combining Propositions (Connectives)

We link simple statements using standard connectors:

OperationSymbolMeaningRule to Remember
NOT$\sim a$NegationFlips True to False, and False to True.
AND$a \wedge b$ConjunctionTrue only if both a and b are True.
OR$a \vee b$DisjunctionTrue if at least one of them is True.
IMPLIES$a \rightarrow b$"If a, then b"False only when a true premise leads to a false result.
IFF$a \leftrightarrow b$"If and only if"True when both have the exact same truth state.

Key Equivalence (Contrapositive): $a \rightarrow b \equiv \sim a \vee b \equiv \sim b \rightarrow \sim a$.

Arrow Notation: $\rightarrow$ is an operation that can be True or False, whereas $\Rightarrow$ means the entire "if-then" statement is guaranteed to be True ($a \rightarrow b \equiv T$).

3. Useful Logical Laws

  • Double Negation: $\sim(\sim a) \equiv a$
  • De Morgan's Laws: $\sim(a \vee b) \equiv \sim a \wedge \sim b$
    $\sim(a \wedge b) \equiv \sim a \vee \sim b$
  • Distributive Laws: $a \vee (b \wedge c) \equiv (a \vee b) \wedge (a \vee c)$
    $a \wedge (b \vee c) \equiv (a \wedge b) \vee (a \wedge c)$

4. Quantifiers

Statements in math usually talk about collections of numbers (Countable Sets, where items can be arranged in a line: $x_1, x_2, x_3, \dots$).

  • Universal Quantifier ($\forall$): "For all" or "For every". The rule holds for every item without exception. To show it is False, you only need one single counterexample.
    $\forall x P(x) \equiv P(x_1) \wedge P(x_2) \wedge P(x_3) \wedge \dots$
  • Existential Quantifier ($\exists$): "There exists at least one". You only need to locate one working case to prove it True.
    $\exists x P(x) \equiv P(x_1) \vee P(x_2) \vee P(x_3) \vee \dots$

Negating Quantifiers: Flip and Negate the claim.
$\sim \forall x P(x) \equiv \exists x \sim P(x)$
$\sim \exists x P(x) \equiv \forall x \sim P(x)$

5. The Three Proof Methods

  • Direct Proof: Start by assuming statement A is true, and follow clean logical steps until you arrive at B.
  • Proof by Contraposition: Instead of proving $A \Rightarrow B$, prove the equivalent claim: "If B is false, then A must be false" ($\sim B \Rightarrow \sim A$).
  • Proof by Contradiction: Assume the opposite of what you want to prove. Show that this assumption forces a ridiculous or impossible outcome. Since the contradiction cannot happen, your initial claim must be true.
