Definition

Definition(Gamma function):

The definite integral
$$ \int_0^\infty e^{-x}x^{n-1}dx, \quad n > 0, $$
is known as the Gamma function and is denoted by $\Gamma(n)$ [read as "Gamma n"]. The Gamma function is also called the Eulerian integral of the second kind.

Thus,
$$ \Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx, \quad n > 0. $$

Properties of Gamma function

  • Show that $\Gamma(1) = 1$.

    Proof: By the definition of the Gamma function,
    $$ \int_0^\infty e^{-x}x^{n-1}dx, \quad n > 0, $$ $$ \Gamma(1) = \int_0^\infty e^{-x}x^{1-1}dx = \int_0^\infty e^{-x}dx = 1 $$
  • Show that $\Gamma(n + 1) = n\Gamma(n), \quad n > 0$.

    Proof: We have from the definition of the Gamma function,
    $$ \Gamma(n + 1) = \int_0^\infty e^{-x}x^{(n+1)-1}dx = \int_0^\infty x^n e^{-x}dx $$
    Applying integration by parts:
    $$ = [x^n(-e^{-x})]_0^\infty - \int_0^\infty (nx^{n-1})(-e^{-x})dx $$ $$ = -\lim_{x\to\infty} \frac{x^n}{e^x} + 0 + n \int_0^\infty (x^{n-1})(e^{-x})dx $$ $$ = n \int_0^\infty (x^{n-1})(e^{-x})dx = n\Gamma(n) $$
  • If $n$ is a non-negative integer, then $\Gamma(n + 1) = n!$

    Proof: We know that for $n > 0$, we have (from property II)
    $$ \Gamma(n + 1) = n\Gamma(n) = n\Gamma(n - 1 + 1) = n(n - 1)\Gamma(n - 1) $$ $$ = n(n - 1)(n - 2)\Gamma(n - 2) $$ $$ = n(n - 1)(n - 2) \dots 3 \cdot 2 \cdot 1 \cdot \Gamma(1) = n! $$

Extension of definition of Gamma function $\Gamma(n)$ for $n < 0$

When $n > 0$, we know that $\Gamma(n + 1) = n\Gamma(n)$ so that
$$ \Gamma(n) = \frac{\Gamma(n + 1)}{n} $$
Let $-1 < n < 0$. Then $-1 < n \implies n + 1 > 0$ so that $\Gamma(n + 1)$ is well defined by definition. Thus $\Gamma(n)$ is defined for $-1 < n < 0$.

Similarly, $\Gamma(n)$ is given by
$$ \Gamma(n) = \frac{\Gamma(n + 1)}{n}, $$
for $-2 < n < -1$, $-3 < n < -2$ and so on. Thus $\Gamma(n)$ defines for all values of $n$ except $n = 0, -1, -2, -3, \dots$

Convergence of the Gamma Function

Lemma: For every $s > 0$ the improper integral
$$ \int_0^\infty e^{-sx}dx < \infty $$
Lemma: Let $n$ be a positive integer. Then
$$ \lim_{x\to\infty} \frac{x^{n-1}}{e^{x/2}} = 0 $$
Theorem: For every $n > 0$ the improper integral $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx$ is convergent.
Proof: We will prove this in three cases:

Case I: $n$ is a positive integer $\ge 1$
By Lemma , $\lim_{x\to\infty} \frac{x^{n-1}}{e^{x/2}} = 0$. By definition of limits, with $\epsilon = 1$, $\exists M$ s.t. $\forall x \ge M$, $\left| \frac{x^{n-1}}{e^{x/2}} \right| < 1$. That means $x^{n-1} < e^{x/2}$, and thus $e^{-x}x^{n-1} < e^{-x}e^{x/2} = e^{-x/2}$. By comparison integral theorem,
$$ \int_M^\infty e^{-x}x^{n-1}dx < \int_M^\infty e^{-x/2}dx < \infty, \quad \text{by 0.7.1} $$
Hence $\Gamma(n)$ is convergent for all positive integers.

Case II: Let $y = n \ge 1$ be any real number.
Let $[y]$ be the largest integer, so that $[y] < y < [y] + 1$. For $x > 0$, $0 \le e^{-x}x^{y-1} \le e^{-x}x^{[y]}$. Since $\int_0^\infty e^{-x}x^{[y]} = \Gamma([y] + 1)$ is convergent (by Case I), we have $\int_0^\infty e^{-x}x^{[y]} < \infty$ by comparison.

Case III: Now let $0 < n < 1$.
Note that $n < 1 \implies n < 2 \implies n - 1 < 1 \implies x^{n-1} < x$.
$$ \frac{1}{e^{x/2}} \le \frac{x^{n-1}}{e^{x/2}} < \frac{x}{e^{x/2}} $$
By applying the Sandwich Theorem, $\lim_{x\to\infty} \frac{x^{n-1}}{e^{x/2}} = 0$. Following similar logic to Case I, there exists $N$ such that $e^{-x}x^{n-1} < e^{-x/2}$, ensuring the upper part of the integral $\int_N^\infty e^{-x}x^{n-1}dx < \infty$.

Now consider the lower part $\int_0^N e^{-x}x^{n-1}dx$. Note that when $0 < n < 1$, $\lim_{x\to 0} e^{-x}x^{n-1} = \infty$. The function is unbounded at $x = 0$. For $x > 0$, $e^{-x}x^{n-1} \le x^{n-1}$. Then,
$$ \int_0^N e^{-x}x^{n-1}dx \le \lim_{\epsilon\to 0^+} \int_\epsilon^N x^{n-1}dx = \lim_{\epsilon\to 0^+} \left[ \frac{x^n}{n} \right]_\epsilon^N = \frac{N^n}{n} < \infty. $$
Thus, for all $n > 0$, $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx < \infty$.

Transformation of Gamma function

  • Form I: Show that $\Gamma(n) = \frac{1}{n} \int_0^\infty e^{-x^{1/n}}dx, \quad n > 0$.

    Proof: By definition, $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx$.
    Put $x^n = t$ so that $nx^{n-1}dx = dt$. Then by definition,
    $$ \Gamma(n) = \frac{1}{n} \int_0^\infty e^{-t^{1/n}}dt, \quad n > 0. $$
    Note: Let $n = 1/2$. Then $\Gamma(1/2) = 2 \int_0^\infty e^{-x^2}dx = \sqrt{\pi}$.
  • Form II: Show that $\int_0^\infty e^{-kx}x^{n-1}dx = \frac{\Gamma(n)}{k^n}; \quad n > 0, k > 0$.

    Proof 0.7.6: By definition, $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx$.
    Put $x = kt$ so that $dx = k dt$. This gives:
    $$ \Gamma(n) = \int_0^\infty e^{-kt}(kt)^{n-1}k dt = k^n \int_0^\infty e^{-kt}t^{n-1}dt $$
    Or in other words, $\int_0^\infty e^{-kx}x^{n-1}dx = \frac{\Gamma(n)}{k^n}$.
  • Form III: Show that $\Gamma(n) = \int_0^1 \left(\log \frac{1}{x}\right)^{n-1}dx; \quad n > 0$.

    Proof 0.7.7: By definition, $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx$.
    Put $e^{-x} = t$ so that $-e^{-x}dx = dt$, then $x = \log \frac{1}{t}$. This gives:
    $$ \Gamma(n) = -\int_1^0 \left(\log \frac{1}{t}\right)^{n-1}dt = \int_0^1 \left(\log \frac{1}{t}\right)^{n-1}dt. $$
  • Form IV: Show that $\Gamma(n) = 2 \int_0^\infty e^{-x^2}x^{2n-1}dx, \quad n > 0$.

    Proof 0.7.8: By definition, $\Gamma(n) = \int_0^\infty e^{-x}x^{n-1}dx$.
    Put $x = t^2$ so that $dx = 2t dt$. This reduces to:
    $$ \Gamma(n) = \int_0^\infty e^{-t^2}(t^2)^{n-1}2t dt = 2 \int_0^\infty e^{-t^2}t^{2n-1}dt. $$

Added Worked Examples

Example A: Evaluating an integral using Form II

Evaluate the integral $\int_0^\infty x^6 e^{-3x} dx$.

Solution: We can match this integral to Form II:
$$ \int_0^\infty e^{-kx}x^{n-1}dx = \frac{\Gamma(n)}{k^n} $$
Comparing terms, we see that $k = 3$ and $n - 1 = 6 \implies n = 7$.

Substitute these values into the formula:
$$ \int_0^\infty x^6 e^{-3x} dx = \frac{\Gamma(7)}{3^7} $$
Using the property $\Gamma(n+1) = n!$ for integer $n$, we know $\Gamma(7) = 6! = 720$.
Therefore, the value of the integral is:
$$ \frac{720}{2187} = \frac{80}{243} $$
Example B: Evaluating an integral using Form IV

Evaluate the integral $\int_0^\infty x^4 e^{-x^2} dx$.

Solution: We match this to Form IV:
$$ \int_0^\infty e^{-x^2}x^{2n-1}dx = \frac{\Gamma(n)}{2} $$
Setting the powers of $x$ equal: $2n - 1 = 4 \implies 2n = 5 \implies n = \frac{5}{2}$.

The integral evaluates to $\frac{\Gamma(5/2)}{2}$. Let's expand $\Gamma(5/2)$ using the property $\Gamma(n+1) = n\Gamma(n)$:
$$ \Gamma\left(\frac{5}{2}\right) = \frac{3}{2}\Gamma\left(\frac{3}{2}\right) = \frac{3}{2} \cdot \frac{1}{2}\Gamma\left(\frac{1}{2}\right) = \frac{3}{4}\sqrt{\pi} $$
Substituting this back in gives the final answer:
$$ \frac{\frac{3}{4}\sqrt{\pi}}{2} = \frac{3\sqrt{\pi}}{8} $$
