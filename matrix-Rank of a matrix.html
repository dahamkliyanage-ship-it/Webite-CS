Rank of a matrix

Definition:

The number of non-zero rows of the row echelon form of a matrix $A$ is defined as the rank of $A$, which is denoted by $\text{Rank } A$.

Detail: The rank essentially tells us the number of linearly independent row vectors in the matrix. If a $3 \times 3$ matrix reduces to having exactly one row of all zeros, its rank is $2$.
Definition:

A matrix $A$ is in column echelon form if its transpose $A^T$ is in row echelon form.
Example 2.

The following matrix is in column echelon form:
$$ \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 2 & -4 & 1 \end{pmatrix} $$
If we were to transpose this matrix, it would result in a standard upper-triangular row echelon form.

Remark. The rank of a matrix can be analogously defined considering the column echelon form. The row rank and column rank of any given matrix are always equal.
