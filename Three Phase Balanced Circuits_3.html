4.0 Three Phase Circuits

Comprehensive analysis of polyphase electrical systems, including Star (Y) and Delta ($\Delta$) topologies, per-phase analysis, power calculations, and the critical behavior of unbalanced loads and neutral currents.

4.1 Introduction to 3-Phase Systems

Why are 3-phase systems the universal standard for power generation and transmission? Most large loads, such as heavy industrial induction motors, require a continuous, non-pulsating 3-phase supply to produce a smooth rotating magnetic field. Even when the power is supplied to domestic residential loads (which only use a single phase), the utility company distributes the bulk 3-phase power evenly among different neighborhoods to maintain strict overall system balance at the generator.

A perfectly balanced 3-phase power source (like a synchronous generator) contains three separate stator coils physically arranged $120^\circ$ apart around the rotor. This physical geometry produces three individual sinusoidal voltages that have the exact same RMS magnitude but are shifted in phase by exactly $120^\circ$ ($\frac{2\pi}{3}$ radians) from one another in the time domain.

4.2 Star (Y) vs. Delta ($\Delta$) Connections

Three-phase sources and loads can be wired in two primary topologies. The choice of topology defines the mathematical relationship between the Line parameters (measured between two outer phases) and the Phase parameters (measured across a single internal coil or load).

Star (Y) vs. Delta ($\Delta$) Topologies

1. Star (Y) Connection

Features a common neutral point. Line current equals Phase current, but Line voltage is greater than Phase voltage.

$$V_{Line} = \sqrt{3} \times V_{Phase}$$

$$I_{Line} = I_{Phase}$$

Example: Domestic distribution networks use Star to provide $400\text{V}$ line-to-line for industry, and $230\text{V}$ line-to-neutral for homes.

2. Delta ($\Delta$) Connection

Components are connected end-to-end forming a closed loop. There is no neutral wire. Line voltage equals Phase voltage.

$$V_{Line} = V_{Phase}$$

$$I_{Line} = \sqrt{3} \times I_{Phase}$$

Example: Heavy industrial induction motors and high-voltage transmission lines typically use Delta topologies.

4.3 Unbalanced Systems & The Floating Neutral

A 3-phase system is Balanced only if the impedances across all three phases are mathematically identical ($Z_R = Z_Y = Z_B$ in both magnitude and phase angle). If single-phase loads (like lighting or computers in different buildings) draw unequal currents, the system becomes Unbalanced.

Neutral Current ($I_N$)

In a Star-connected 4-wire system, applying Kirchhoff's Current Law (KCL) at the star node ($N$) reveals that the neutral wire acts as a vital return path for residual current. Using complex phasor addition:

$$\mathbf{I}_N = \mathbf{I}_R + \mathbf{I}_Y + \mathbf{I}_B$$

If the system is perfectly balanced, $\mathbf{I}_N = 0\text{ A}$. However, in an unbalanced system, the vector sum does not cancel out, and a physical current flows through the neutral wire back to the source.

The Danger of a Broken (Floating) Neutral

If an unbalanced 3-phase Star system lacks a neutral wire (or if the neutral wire physically breaks), the return path for the unbalanced current is destroyed. Because KCL dictates that the currents entering the node must sum to zero ($I_R + I_Y + I_B = 0$), the physical voltage of the star point ($V_N$) is violently shifted away from Earth potential ($0\text{V}$) to force the currents into balance.

Floating Neutral Phasor Shift

The Consequence: The voltage drops drastically across the phase with the heaviest load (lowest impedance), and spikes dangerously across the phases with the lightest loads (highest impedance). A broken neutral in a residential grid can cause $230\text{V}$ outlets to surge to nearly $400\text{V}$, instantly destroying electronics and sparking fires.

4.4 3-Phase Power Calculations

The total Active Power ($P$) securely transmitted in a balanced 3-phase system can be calculated using either the internal Phase values or the externally measurable Line values. Both formulas yield the exact same total power.

Using Internal Phase Values:

$$P_{total} = 3 \times V_{Phase} \times I_{Phase} \times \cos(\Phi)$$


Using External Line Values (Industry Standard):

$$P_{total} = \sqrt{3} \times V_{Line} \times I_{Line} \times \cos(\Phi)$$

Where $\cos(\Phi)$ is the system Power Factor, and $\Phi$ is strictly defined as the specific phase angle difference between the phase voltage and the phase current at the load.

Worked Example: Neutral Current & Unbalanced Loads

A $400\text{V}$ (Line), 3-phase, 4-wire Star system has three purely resistive single-phase loads connected: Phase R ($23\ \Omega$), Phase Y ($23\ \Omega$), and Phase B ($11.5\ \Omega$). Calculate the Neutral Current.

1. Identify Phase Voltages (Polar Form):
$V_{Phase} = 400 / \sqrt{3} = 230\text{V}$.
$\mathbf{V}_R = 230\angle0^\circ\text{ V}$
$\mathbf{V}_Y = 230\angle-120^\circ\text{ V}$
$\mathbf{V}_B = 230\angle120^\circ\text{ V}$

2. Calculate Phase Currents using Ohm's Law ($\mathbf{I} = \mathbf{V}/\mathbf{Z}$):
$\mathbf{I}_R = 230\angle0^\circ / 23 = \mathbf{10\angle0^\circ\text{ A}}$
$\mathbf{I}_Y = 230\angle-120^\circ / 23 = \mathbf{10\angle-120^\circ\text{ A}}$
$\mathbf{I}_B = 230\angle120^\circ / 11.5 = \mathbf{20\angle120^\circ\text{ A}}$

3. Convert to Rectangular Form to Sum for Neutral Current ($\mathbf{I}_N$):
$\mathbf{I}_R = 10 + j0$
$\mathbf{I}_Y = 10\cos(-120^\circ) + j10\sin(-120^\circ) = -5 - j8.66$
$\mathbf{I}_B = 20\cos(120^\circ) + j20\sin(120^\circ) = -10 + j17.32$

$\mathbf{I}_N = \mathbf{I}_R + \mathbf{I}_Y + \mathbf{I}_B = (10 - 5 - 10) + j(0 - 8.66 + 17.32)$
$\mathbf{I}_N = \mathbf{-5 + j8.66\text{ A}}$

Magnitude of Neutral Current:
$|\mathbf{I}_N| = \sqrt{(-5)^2 + (8.66)^2} = \sqrt{25 + 75} = \sqrt{100} = \mathbf{10\text{ Amperes}}$

Conclusion: The unbalanced $11.5\ \Omega$ load on Phase B forces a massive $10\text{A}$ return current through the neutral wire.
