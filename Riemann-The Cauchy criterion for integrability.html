The Cauchy Criterion

The following theorem gives a criterion for integrability that is analogous to the Cauchy condition for the convergence of a sequence.

Theorem(Cauchy Criterion for Integrability):

A bounded function $f : [a,b] \to \mathbb{R}$ is Riemann integrable if and only if for every $\epsilon > 0$ there exists a partition $P_\epsilon$ of $[a,b]$, which may depend on $\epsilon$, such that:
$$ U(f, P_\epsilon) - L(f, P_\epsilon) \le \epsilon $$


Proof:
  • ($\Leftarrow$) Let $\epsilon > 0$. If such a partition exists, then $U(f) - L(f) \le U(f, P_\epsilon) - L(f, P_\epsilon) < \epsilon$. Since $\epsilon$ is arbitrary, it follows that $U(f) = L(f)$, and so $f$ is integrable.
  • ($\Rightarrow$) Assume $f$ is integrable on $[a,b]$. Then $L(f) = U(f)$. Given $\epsilon > 0$, there exist partitions $P_1$ and $P_2$ such that $L(f) - \frac{\epsilon}{2} < L(f, P_1) \le \int_a^b f = L(f) = U(f) \le U(f, P_2) \le U(f) + \frac{\epsilon}{2}$.
  • Let $P_\epsilon = P_1 \cup P_2$ be the common refinement of $P_1$ and $P_2$. Then:
    $$ U(f, P_\epsilon) - L(f, P_\epsilon) \le U(f, P_2) - L(f, P_1) $$ $$ \le (U(f) + \epsilon/2) - (L(f) - \epsilon/2) = \epsilon $$
    Thus, a partition $P_\epsilon$ with the desired property exists.

Integrability of Monotonic and Continuous Functions

Theorem: Monotonic Functions

Every monotonic function $f$ on $[a,b]$ is integrable.

Proof(Assuming $f$ is increasing):
We assume $f(a) < f(b)$, otherwise $f$ would be a constant function. Since $f(a) \le f(x) \le f(b)$ for all $x \in [a,b]$, $f$ is clearly bounded on $[a,b]$. Let $P = \{x_0, x_1, \dots, x_n\}$ be a partition of $[a,b]$ satisfying $\Delta x_k < \delta = \frac{\epsilon}{f(b)-f(a)}$ for all $k = 1, \dots, n$.
As $f$ is monotonically increasing, $M_k = f(x_k)$ and $m_k = f(x_{k-1})$. By telescoping series, this evaluates to:
$$ U(f, P) - L(f, P) \le \sum_{k=1}^n [f(x_k) - f(x_{k-1})] \frac{\epsilon}{f(b) - f(a)} = [f(b) - f(a)] \frac{\epsilon}{f(b) - f(a)} = \epsilon $$
By Theorem, we have the result.
Theorem: Continuous Functions

If $f$ is continuous on $[a,b]$, then it is integrable.

Proof:
Since $f$ is continuous on the compact set $[a,b]$, it is uniformly continuous on $[a,b]$. Let $\epsilon > 0$. There exists $\delta > 0$ such that $|f(x) - f(y)| < \frac{\epsilon}{2(b-a)}$ whenever $x, y \in [a,b]$ and $|x - y| < \delta$.
Let $P$ be a partition satisfying $\Delta x_k < \delta$. On any subinterval, the function achieves its minimum $m_k = f(y_k)$ and maximum $M_k = f(z_k)$. Since $|y_k - z_k| \le \Delta x_k < \delta$, it follows that $M_k - m_k < \frac{\epsilon}{2(b-a)}$.
$$ U(f, P) - L(f, P) = \sum_{k=1}^n (M_k - m_k)\Delta x_k < \frac{\epsilon}{2(b-a)} \sum_{k=1}^n \Delta x_k = \epsilon $$
By the Integrability Criterion, $f$ is integrable on $[a,b]$.

Discontinuities and Subintervals

Important Notes on Discontinuities:
  • If the set of points of discontinuity of a bounded function $f : [a,b] \to \mathbb{R}$ is finite, then $f$ is Riemann integrable on $[a,b]$.
  • If the set of points of discontinuity of a bounded function $f : [a,b] \to \mathbb{R}$ is a finite number of limit points, then $f$ is integrable on $[a,b]$.
  • i.e., A function may have infinitely many discontinuous points, but if the set of all discontinuous points have a finite number of limit points, then $f$ is integrable on $[a,b]$.
Theorem & Proof
If $f : [a,b] \to \mathbb{R}$ is bounded, and $f$ is integrable on $[c,b]$ for all $c \in (a,b)$, then $f$ is integrable on $[a,b]$.
Proof Idea: We can isolate the endpoint $a$ by choosing a point $x_1$ close enough to $a$ such that the contribution to $U(f,P) - L(f,P)$ on $[a, x_1]$ is $(M_1 - m_1)(x_1 - a) < 2M(x_1 - a) < \frac{\epsilon}{2}$. Because $f$ is integrable on $[x_1, b]$, there exists a partition $P_1$ such that $U(f, P_1) - L(f, P_1) < \frac{\epsilon}{2}$. Combining these gives a total difference of less than $\epsilon$.
Theorem:
Let $f$ be a bounded function on $[a,b]$ that is continuous on every subinterval $[c,b]$ where $c \in (a,b)$. Then $f$ is integrable on $[a,b]$. An analogous result holds at the other endpoint.

Theorem:
If $f$ is a bounded function on $[a,c]$ and integrable on $[a,b]$ and $[b,c]$, where $a < b < c$, then $f$ is integrable on $[a,c]$.

Worked Examples

Example: Integrable but NOT Continuous

Define $f : [0, 2] \to \mathbb{R}$ by $f(x) = 1$ if $x \neq 1$, and $f(x) = 0$ if $x = 1$.

Let $\epsilon$ satisfy $0 < \epsilon < 1$. Then for the partition $P = \{0, 1 - \epsilon/3, 1 + \epsilon/3, 2\}$ of $[0, 2]$, we have:
$$ U(f, P) = 1(1 - \epsilon/3) + 1(2\epsilon/3) + 1(1 - \epsilon/3) = 2 $$ $$ L(f, P) = 1(1 - \epsilon/3) + 0(2\epsilon/3) + 1(1 - \epsilon/3) = 2 - \frac{2\epsilon}{3} $$
Then $U(f, P) - L(f, P) = 2 - (2 - \frac{2\epsilon}{3}) = \frac{2\epsilon}{3} < \epsilon$. By the Integrability Criterion, $f$ is integrable on $[0, 2]$, and we have $\int_0^2 f = 2$.
Example: Infinite Discontinuities with a Finite Limit Point

Let $f : [0, 1] \to \mathbb{R}$ such that $f(x) = 1$ if $x = 1/n; n \in \mathbb{N}$, and $f(x) = 0$ otherwise.

Since $1/n \to 0$, there exists $N$ such that $1/n \in [0, \epsilon]$ for all $n > N$. So only a finite number of $\frac{1}{n}$'s lie in the interval $[\epsilon, 1]$. Cover these finite number of $\frac{1}{n}$'s by intervals such that the sum of the length of these $m$ intervals is less than $\epsilon$. Consider the partition $P = \{0, \epsilon, x_1, x_2, \dots, x_m\}$.

It is clear that $U(P, f) - L(P, f) < 2\epsilon$. Hence by the Integral criterion, the function is integrable. Since the lower integral is $0$ and the function is integrable, $\int_0^1 f(x)dx = 0$.
